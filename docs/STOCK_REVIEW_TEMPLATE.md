## 验收与后续纠错

- [ ] 账户与任务约束已核对。
- [ ] 新闻及未解除事件已核查。
- [ ] 重大利空已经影响准入和决策，未被目标价或低估值抵消。
- [ ] 盈利、现金流、财年、拆股与一次性项目已核对。
- [ ] 同额比较、全账户风险、成本与最强反对意见已处理。
- [ ] 发布前已复查；正文和最终操作状态一致。
- [ ] 私人财务信息、密钥与受限制数据未进入公开记录。

更正记录保留原判断、时间、新事实、错误类型及更新后的操作结论。不得用事后涨跌改写原先可知信息。
