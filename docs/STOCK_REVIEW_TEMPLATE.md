## 卖出与买入配套验收（2026-11-04北京重申）

- [ ] 卖出前已有明确且独立合格的买入端，完成同额、同期限及组合风险比较。
- [ ] 先卖后买/部分成交/分日仅为执行过渡，最终目标不是留现金；没有合格买入端不先卖。
- [ ] 已满10只时，部分卖后买新代码不会导致11只；如加仓已有代码，已独立核其新增资格和集中度。
- [ ] 不用未通过候选补单；未成交/部分成交/买价失效有重算条件，旧暂停配对不自动恢复。
- [ ] 计划、实际确认成交、挂单及待核分别记录；建议撤回不等于代取消订单。
