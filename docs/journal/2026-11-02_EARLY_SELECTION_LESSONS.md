# 早期选股经验与后期标准漂移

记录日期：2026-11-02，Asia/Shanghai。本文保存研究方法、成功解释的证据边界与纠错；不披露个人持仓标识、数量、成本、实际成交、余额或组合收益。现行标准以[选股流水线](../STOCK_SELECTION_PIPELINE.md)为准，本文不新增股票买卖建议。

## 1. 对“初始9只为什么成功”的当前回答

可重复的经验是：**已经存在的盈利能力＋可核查的业务进展＋没有透支增长的价格＋不同业务风险的分散＋给兑现留时间。** 后期部分推荐偏向远期增长和更高估值倍数，而对旧股采用更严格的现金折减；这种不对称会人为制造换股优势，必须纠正。

这是一组有记录支持、仍需检验的解释，不是“9只全部成功”或“早期策略已经证明有效”的统计结论。完整初始9只的同一时点推荐原文和统一总回报数据集尚未全部恢复。不能从后来的持仓快照拼名单，不推补第9只，也不能用下一轮研究名单替代。

本次记录三项已经能完成的工作：归纳早期已恢复的研究主题；承认后期具体研究与执行失误；把统一标准写入后续必读规范和模板。名单、同期间绩效及原因识别的缺项保留，不能用规则归档冒充已经完成回测。

## 2. 早期研究中值得保留的部分

以下为脱敏主题归纳，不是完整初始名单、个人持有清单或逐字推荐原文。早期理由的部分依据来自已恢复摘要，全文尚未全部可审计；不能声称当时每项现金检查均已完成。

| 研究案例 | 已恢复的研究主题 | 可重用机制 | 当时和现在都必须保留的反方 |
| --- | --- | --- | --- |
| G | 已有盈利，项目进展与价格匹配 | 不需要极高增长，也可能因盈利兑现和估值修复获益 | 项目执行、AI压价、预收款和回款时点；后续评级变动不能倒填成最初买因 |
| DFIN | 软件转型与现金回报 | 转型可见度与价格一起判断，等待经营结果验证 | 季节性、养老金项目、SBC及资本市场交易周期；原现金目标不是已收到的现金 |
| AXS | 承保盈利与账面价值提供估值依据 | 经营能力相对价格的吸引力 | 灾损、准备金、费率和底层承保质量；低PB不能掩盖恶化 |
| DOX | 长期合同支持业务可见度 | 可持续盈利、合同与价格补偿相结合 | 低增长、反复重组、业务出售及续约压价；合同期限不等于利润增长 |
| OSIS | 已披露订单与盈利指引提供验证点 | 真实订单逐步转为收入、利润和回款 | 框架上限与已执行订单分开；交付、利润率、现金释放未必持续 |

这些案例不能概括为“只买低PE”。行业、资本需求及盈利质量不同，单一倍数无法统一排序。要保留的是对增长付出的价格、经营兑现证据和股东现金要求，而非固定股票名单。

## 3. 成功机制支持到哪一步

### 已有观察

既有[10月22日事件复盘](2026-10-22_CAUSAL_EVIDENCE_REVIEW.md)记录了部分传统行业与科技风格分化，以及公司业绩、订单或评级事件。它同时保留价格范围、时点与归因限制，没有估计选股alpha或单条新闻的因果贡献。

R在10月22日披露可比EPS4.33，高于原预期，并上调全年指引至14.85–15.05。这是当时盈利改善的可核催化，不是可倒填的首次研究理由，也不证明其属于完整初始9只。

### 合理机制与替代解释

- **价格补偿：** 较低的进入估值可能减少对高增长和倍数扩张的依赖；需用当时的正常化盈利核验，不能看涨后价格倒推。
- **经营兑现：** 订单交付、客户项目和盈利上修可能令市场重新定价；合同额、收入、利润及回款必须分开验证。
- **分散：** 不同业务可能降低对同一科技或高估值因子的依赖；市场风格轮动也可能解释部分表现，不能全部记为个股选择能力。
- **持有时间：** 早期标的有更长兑现窗口；与后来刚买入的标的直接比较累计盈亏，会混入持有期和市场环境差异。

上述机制还没有可靠的份额分解。不能写成盈利改善贡献多少、轮动贡献多少，也不能给未经估计的概率。已有有利与不利案例都要保留，不能把早期说成全胜、后期说成全败。

## 4. 后期偏离与必须承认的失误

| 问题 | 可核事实或研究记录 | 固定下来的修正 |
| --- | --- | --- |
| 新旧两端尺度不同 | 候选接受较乐观增长／较高倍数，旧股接受更严格现金及风险折减的情形 | 同一期限、财年、正常化原则及风险尺度；列无倍数扩张和小幅误差情景 |
| 已知风险未充分改变排名 | BKNG正式监管调查已知时仍列优先候选，且操作表述不一致；既有流水线已记录 | 新闻先决定新增资格，再做排名；风险提示不能代替决策变化 |
| 关键现金拆分完成得太晚 | STRL早期估值偏向乐观盈利情景，一般可用现金、合资现金与非控股权益的核查不充分 | 推荐前核清普通股现金归属；不得把合并现金／合并FCF全算作普通股资源 |
| 模型被当成独立证据 | EPS乘转换率可以作为资本模型，但不是另读现金表所得的独立验证 | 标明模型依赖、资本约束和数据缺口，不靠两套共享假设的估值互相证明 |
| 研究排名变成交易理由 | 观察池第一名或Top5被过早推进为替换现股的理由 | 新股独立值得配置、相对旧股值得替换分别证明；允许零推荐 |

这些属于研究和执行问题，不能仅归结为短期波动或交易磨损。亏损不是流程失误的唯一证据，盈利也不能抹去已知遗漏。

## 5. 今后的操作性标准

1. 先核对已有盈利、可核业务进展和未解除重大事件，再建立未来预测。
2. 核对归属普通股股东的现金，处理必要capex、持续费用、SBC、营运资本及非控股权益；利润已经计入的成本不重复扣。
3. 公司指引、分析师预测和研究者假设分列；分析师目标价和网友讨论只作线索与反方材料。
4. 当前价格必须有可解释的余量；不能只靠更远年度盈利或倍数扩张制造便宜。
5. 新旧两端同尺度比较，全账户共同因子也要比较。多个候选对应同一换出对象时，执行方案互斥，不能重复使用同一笔资金；具体个人持仓与执行安排不在公开文档披露。
6. 100只是覆盖范围，Top5是研究优先，不是五张买单。研究持续进行，不要求交易持续发生。
7. 2026-11-02起不再预扣固定2.5%磨损，按两端限价与已确认费用处理；限价不保证成交，等待现金路径必须保留。
8. 标准或权重变更必须说明新证据和影响。买后发现的可避免遗漏按版本保留，不能为维护旧推荐补写理由。

规则详见[现行流水线](../STOCK_SELECTION_PIPELINE.md)，每次推荐使用[复核模板](../STOCK_REVIEW_TEMPLATE.md)，结果使用[投资日志模板](../INVESTMENT_JOURNAL_TEMPLATE.md)。
