# 投资研究与操作日志模板

建立于2026-10-23，更新于2026-11-02，北京时间。适用于每日持仓与候选股研究、买入前决策、持有期复核与事后事件研究。完整选股规则见 [STOCK_SELECTION_PIPELINE.md](STOCK_SELECTION_PIPELINE.md)。

日志按记录 ID 追加。原始决策、事件发生、首次公开、实际读取、报价和成交分别记录时间，不用事后解释覆盖原判断。公开版本只保存通用研究案例；账户、股数、成本、余额、具体成交与个人组合表现保存在私人日志。

## 4. 涨跌与收益算术归因

公开案例可记录证券与基准的行情，但不公开个人持仓贡献。私人日志另存数量、成本和成交依据。

| 字段 | 填写内容 |
| --- | --- |
| 行情来源、原始报价时间及延迟 | |
| 参考基价和当前价 | 明确昨收、事件前价或其他基价；不得互换 |
| 原始价格涨跌与含息收益 | 复权、股息、币种和汇率口径分别说明 |
| 同期主要市场、等权市场、行业及同行收益 | 标明相同时段及不同步部分 |
| 相对收益／模型残差 | 写具体公式及适用窗口；未估计则留空 |
| 私人收益贡献 | 单列数量与价格变化、交易、现金、费用及资金流 |
| 无法核实的数据 | 未知不填 0 |

固定股数的算术贡献为“股数 × 同口径价格变化”；组合百分比以相同起点的市值加总为分母。不能平均个股百分比。若使用当前股数回溯价格，应称“当前持仓回溯表现”；有日内交易或资金流时，不等于账户实际收益。

相对基准上涨、异常收益和贡献占比都不自动构成因果效应。盘中、收盘及盘后快照分别保存，不把后来快照覆盖前一快照。

## 5. 事件事实与归因证据

“事实核验”与“归因支持”使用两个独立字段，不给人为概率或装饰性分数。

- 事实核验：原始文件已读／可追溯二手记录／待核／来源冲突。
- 归因支持：仅算术结果／同期事件与机制一致／同行走势一致／机制假说／无法判断。
- 只有写明识别设计与关键假设并提供检验后，才可使用“已识别因果效应”。公告真实、时间先于涨跌，仍不足以单独满足此项。

| 事件及机制 | 事件／首次公开／读取时间 | 来源 | 事实核验 | 归因支持 | 竞争解释、未知项及限制 |
| --- | --- | --- | --- | --- | --- |
| | | | | | |

检查事项：

1. 新公告、旧消息重发、历史 13F 持仓披露和分析师评论分开。
2. 目标价调整与评级调整分开；记录是否可能在回应已有走势。
3. 合同期限、金额、交付、利润和回款分开；长期合同不直接等于当期利润上修。
4. 多信息财报中的收入、利润、指引、回购及管理层表述可能共同影响价格，不能将全部涨幅归给单个数字。
5. 未检索到新消息不等于没有新消息；“未找到独立催化”是合格结果。
6. 上涨不自动解除调查、诉讼、会计或融资风险；解冻须另外留下新证据。

事件研究的异常收益首先是模型相对结果。一个事件日加若干同行，不足以自行证明平行趋势或 DiD 识别成立。没有可信反事实时，保留机制和时序证据，不升级为确定因果。

## 10. 固定分组与换股反事实（2026-11-02新增）

先锁定原始分组名单、纳入日期、原始推荐记录和证据状态。缺少成员、原文或起点时标未确认；不能从后来持仓倒推“初始9只”，也不能只保留早期赢家。初始推荐、后来替换、未执行方案分组记录。

对每次替换，以同一决策起点、相同初始资金及相同终点评价两个路径：

| 字段 | 换入方案 | 继续持有原股 | 数据／假设状态 |
| --- | --- | --- | --- |
| 原始决策与成交时点；二者不相互代替 | | | |
| 同一初始资金及买卖限价条件 | | | |
| 实际成交／部分成交／未成交／纯研究情景 | | | |
| 先卖后买之间的现金及等待时间 | | | |
| 期末证券价值、残余现金、股息 | | | |
| 已知实际费用；税务已知项与未知项 | | | |
| 同期市场及事前选择的行业／风格对照 | | | |
| 价格变化、经营兑现和倍数变化 | | | |
| 同期回撤与共同风险暴露变化 | | | |

令W0为相同起点资金，W换为新股期末价值＋残余现金＋期间分红，W留为原股期末价值＋期间分红；两边按同一已知费用和税务口径处理。记录增量财富W换−W留，以及(W换−W留)/W0。使用已含股息的总回报序列时不再加一次分红。按整股执行时保留向下取整与余款，未买到期间保留现金，不假设理想成交。

当前口径不预扣固定2.5%磨损，限价不保证成交；未知项目不填零。尚未执行的方案只记研究假设，不冒充实际换股结果。

分别保存：事前理由、观察到的结果、机制假说、尚缺的验证。各股从不同买入日计算的盈亏可描述账户体验，不能直接证明换股有效或初始选股规则优于后期规则。完整比较须覆盖赢家、输家、退出和未成交案例，保留过程错误，即使结果盈利也不删除。

## 11. 每日研究与候选池维护：没有交易也必须分析（2026-11-02补充）

日常报告同时包含持仓复核、候选池研究和操作理由。不能因无交易而只写“继续观察”，也不能把逐日筛查写成100家公司已全部完成深度尽调。行情、经营解释和因果证据分别记录。

### 日常必做内容

| 模块 | 必须记录的内容 | 验收与缺项处理 |
| --- | --- | --- |
| 全部持仓覆盖（私人） | 核对最新可见账户、用户报告但未同步的交易及日期；逐只分析，基金另列并纳入共同风险 | 私人清单与当轮覆盖做集合核对；数据滞后、未确认增减和缺项明确，不能只写操作过的股票 |
| 走势及比较 | 同口径收盘、1/5/20交易日收益，适用市场与行业对照；盘前/盘后另列时间、来源、延迟 | 区分价格事实、机制解释和未确认归因；拆股/股息及缺失不混用，不以单日强弱替代中线判断 |
| 业务、新闻与分析师 | 新财报/指引、订单与回款、普通股现金/资本、重大未解除事件、具名评级与目标价变化 | 事实、发生/首次公开/读取时间及来源可追溯；旧闻重发不当新催化，无检索结果不等于没有消息 |
| 全100只日常筛查 | 每只记录最后复核日、当日行情/事件检查状态、研究深度、当前资格与下一验证点；优先深入发生变化的公司 | 完成数/总数、价格/新闻/基本面各自覆盖与未完成代码明示；旧来源不能改日期冒充新核查 |
| 候选资料维护 | 有已核实变化时，更新现行CSV及WATCHLIST_100.md相应资料、事件日期、来源、风险、资格和待核问题 | 更新资料不等于换成员；表格及CSV对齐，保留旧版本、变更时间及依据 |
| 候选成员调整 | 检查有无更好的新研究对象；明确本轮增补、移出或不调整及理由，旧成员保留备选档 | 依既定标准保持100个唯一代码并覆盖全部已核实现股；不因追涨、掩盖下跌或凑更新次数换名单；有效旧风险继续承接 |
| 决策及变化原因 | 买卖/不操作理由、相对前一日与同日早先结论的变化、最强反方、下一事件和失效条件 | 区分新事实、价格变化、模型纠错、用户约束；未完成比较不自动等于持有或卖出 |

公开研究对全池使用相同字段，不单独标出哪些是个人持仓。个人数量、成本、账户、余额、实际成交/挂单及收益贡献只留私人记录。获准进入研究池、通过新增资格和形成可执行换股方案是三个不同状态。

### 晨间复盘与晚间方案分工

- 晨间报告覆盖刚结束常规交易的美国日期：复盘全部持仓和100只池的走势与事件，更新资料及成员变更台账，保留当时操作理由。休市日不制造日收益，仍检查新事件及待核问题。
- 晚间方案读取晨间成果，补查全池新增重要事件、全部持仓及重点候选的盘前变化，重算对交易有影响的价格、盈利和现金假设。不能直接复制前日建议或旧限价。
- 晚间先给可核实方案及研究缺项；完整明细另附，不为凑Top5强行给买单。未完成的价格或关键事实不得编成精确指令。
- 两篇按对应美国日期相互链接；保留事前版本，事后事实及纠错按时间追加。信息缺失和归档失败如实记录，不称已全面更新或已保存。
