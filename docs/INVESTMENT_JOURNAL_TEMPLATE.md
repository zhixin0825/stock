# 投资日志模板

版本：2026-10-23，北京时间。适用于买入前决策、持有期复核与事后事件研究。完整选股规则见 [STOCK_SELECTION_PIPELINE.md](STOCK_SELECTION_PIPELINE.md)。

日志按记录 ID 追加。原始决策、事件发生、首次公开、实际读取、报价和成交分别记录时间，不用事后解释覆盖原判断。公开版本只保存通用研究案例；账户、股数、成本、余额、具体成交与个人组合表现保存在私人日志。

## 4. 涨跌与收益算术归因

公开案例可记录证券与基准的行情，但不公开个人持仓贡献。私人日志另存数量、成本和成交依据。

| 字段 | 填写内容 |
| --- | --- |
| 行情来源、原始报价时间及延迟 | |
| 参考基价和当前价 | 明确昨收、事件前价或其他基价；不得互换 |
| 原始价格涨跌与含息收益 | 复权、股息、币种和汇率口径分别说明 |
| 同期主要市场、等权市场、行业及同行收益 | 标明相同时段及不同步部分 |
| 相对收益／模型残差 | 写具体公式及适用窗口；未估计则留空 |
| 私人收益贡献 | 单列数量与价格变化、交易、现金、费用及资金流 |
| 无法核实的数据 | 未知不填 0 |

固定股数的算术贡献为“股数 × 同口径价格变化”；组合百分比以相同起点的市值加总为分母。不能平均个股百分比。若使用当前股数回溯价格，应称“当前持仓回溯表现”；有日内交易或资金流时，不等于账户实际收益。

相对基准上涨、异常收益和贡献占比都不自动构成因果效应。盘中、收盘及盘后快照分别保存，不把后来快照覆盖前一快照。

## 5. 事件事实与归因证据

“事实核验”与“归因支持”使用两个独立字段，不给人为概率或装饰性分数。

- 事实核验：原始文件已读／可追溯二手记录／待核／来源冲突。
- 归因支持：仅算术结果／同期事件与机制一致／同行走势一致／机制假说／无法判断。
- 只有写明识别设计与关键假设并提供检验后，才可使用“已识别因果效应”。公告真实、时间先于涨跌，仍不足以单独满足此项。

| 事件及机制 | 事件／首次公开／读取时间 | 来源 | 事实核验 | 归因支持 | 竞争解释、未知项及限制 |
| --- | --- | --- | --- | --- | --- |
| | | | | | |

检查事项：

1. 新公告、旧消息重发、历史 13F 持仓披露和分析师评论分开。
2. 目标价调整与评级调整分开；记录是否可能在回应已有走势。
3. 合同期限、金额、交付、利润和回款分开；长期合同不直接等于当期利润上修。
4. 多信息财报中的收入、利润、指引、回购及管理层表述可能共同影响价格，不能将全部涨幅归给单个数字。
5. 未检索到新消息不等于没有新消息；“未找到独立催化”是合格结果。
6. 上涨不自动解除调查、诉讼、会计或融资风险；解冻须另外留下新证据。

## 6. 反事实与因果识别

| 字段 | 填写内容 |
| --- | --- |
| 待识别问题与处理事件 | |
| 若无该事件，合理反事实是什么 | |
| 主要基准与同行 | 尽量按事件前业务、规模、估值及风险选择 |
| 选择时点 | 事前固定／本轮事后选择；后者必须披露 |
| 事前估计窗口及有效观测数 | |
| 事件窗口及时间对齐 | 公告前、公告后、盘后至次日分开 |
| 市场／行业／风险因子模型 | 参数来源、训练期间、残差及不确定性 |
| 控制对象污染与信息溢出 | 同行或行业 ETF 可能同受事件影响 |
| 同期竞争事件 | 宏观、行业、其他公司信息和流动性 |
| 可支持的结论 | 算术、相关性、事件一致性或具有明确假设的因果效应 |
| 无法支持的结论 | |

事件研究的异常收益首先是模型相对结果。一个事件日加若干同行，不足以自行证明平行趋势或 DiD 识别成立。没有可信反事实时，保留机制和时序证据，不升级为确定因果。

## 7. 结果与过程分别评价

| 检查对象 | 记录 |
| --- | --- |
| 投资结果 | 盈亏、相对基准、期间回撤；不据此直接判流程好坏 |
| 决策过程 | 是否使用当时信息、新闻门槛、口径一致及替代比较 |
| 原假说验证 | 已验证／部分支持／被否定／仍待观察，并写变量 |
| 新增事实导致的变化 | |
| 当时未买的候选及对照 | 防止只记录赢家或事后挑控制 |
| 错误及更正 | 错误类型、发现日期、受影响判断、修正依据；保留旧版本 |

盈利不能抵消已知重大风险被忽略的流程错误；亏损也不自动证明经过完整研究的决策无效。须保留全部研究对象，包括下跌、退出及未买候选。
