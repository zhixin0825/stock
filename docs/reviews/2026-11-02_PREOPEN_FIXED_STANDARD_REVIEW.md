## 2. HII与AMP：盈利真实，旧相对优势未获验证

### 两端已有经营与风险证据

- **AMP正面：** Q3剔除保险假设变更的经营EPS12.07，经营利润同比增长14%；剔除Comerica转出后的财富净流入53亿美元。风险是资产管理仍净流出，利润受市场资产价格影响。
- **AMP资本：** 官方演示稿披露估计RBC462%、过剩资本20亿美元及管理层口径可用流动性23亿美元。后者不全是现金；10-Q中的母公司现金及无抵押流动证券约10亿美元。
- **HII正面：** 订单及业务可见度支持中期经营，现金计划未被本轮新公告撤回；本轮未核实到新的紧急退出事件。
- **HII风险：** Q3 GAAP EPS5.48包含1.52的有利EAC累计追溯调整；9M CFO9900万美元、FCF负1.82亿美元，净合同资产增长，现金兑现仍需验证。计划不等于到账。

### 独立资本核对与旧模型更正

AMP 10-Q披露9M子公司上游股息或资本返还28亿美元、向子公司注资3亿美元，净上游25亿美元。按九个月简单年化并除以9140万股约为36.47美元/股，尚未扣母公司成本，且包含资本返还，不能当永续股东现金。

这项证据不能独立验证旧模型“2027 EPS50×90%=45美元/股”的可分配现金假设。公司约90%的FCF生成指标也须标为公司口径，不能与独立现金核查混为一谈。

旧模型给予AMP一定倍数提升，同时对HII采用较低终值倍数及养老金处理，放大了换股空间。尚未完成两端参考倍数及EAC、养老金、季节性的可复核归一化，旧相对优势不能据此确认；因此不再发布旧562.5目标为已获现金证实的价值，也不给新的精准买入点。

**当前判定：AMP保持研究候选；不单为筹资买AMP而出售HII。HII的观察依据是订单与业务，限制是现金转换；不建议新增。**

## 3. DOX与ADBE：无倍数扩张下差距较小

以下仅保留旧盈利假设作稳健性检验，期限约一年；不以它代替完整逐季日历化估值，也不是公司承诺。固定的是各自入场时正常化盈利的参考倍数，不是强迫不同企业使用同一个PE。

| 检验输入／结果 | ADBE | DOX较强分支 |
| --- | --- | --- |
| 原研究入场价 | 250 | 65 |
| 盈利起点及依据 | FY26官方GAAP EPS中点18.145 | 正常化FY26 EPS5.92 |
| 下一期盈利假设 | 自估19.5 | 自估增长3%至6.0976 |
| 年股息假设 | 0 | 2.276 |
| 保持各自参考PE不变的价格回报／含息回报 | 约7.47% | 约6.50% |
| 最重要未知 | FY27现金增长、净股数与AI竞争 | 新重组成本R、Vubiquity出售后的净EPS影响d |

DOX5.92的桥为9M GAAP3.33加重组影响1.07，再加Q4指引中点1.52；保留SBC和摊销。较强分支R=0、d=0仅用于检验，不能当已确认。若重组持续，或处置后的净利润影响较大，比较可能改判；d不是重组成本。

ADBE旧331.5盈利估值和328.42现金估值含有重估或净股数下降假设。以7.8bn自估股东现金、400m股、维持7.8%现金收益率只对应250；降至380m股也仅约263.16，而回购需要资金。不能默认得到380m股，再把相同回购资金重复计入股东回报。

实际现金交叉核对：DOX9M CFO518.983m减净capex78.769m、SBC83.692m和非控股分配3.113m，约353.409m；710–730m公司FCF指标排除重组现金，口径不同。ADBE9M CFO7.646bn减PPE0.180bn和SBC1.582bn约5.884bn；尚未精拆80m长期投资、无形资产及其他资产混合行。两者都不能机械年化当预测。

**当前判定：不启动原65/250配对，不因250价格被触及而自动买ADBE。DOX新年度指引即将公布，暂不替未知R、d作有利假设。**
